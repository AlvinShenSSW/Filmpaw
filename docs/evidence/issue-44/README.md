用户确认在打开双栏归档目录时出现错误，未开始传输。使用只读句柄在报告目录和三个祖先目录复现：

| 检查 | 修复前结果 | 修复后结果 |
| --- | --- | --- |
| 原生128位身份查询 `FileIdInfo` | 四个目录均返回错误87 | 接口仍返回87，按明确能力错误回退 |
| 属性、最终路径、卷文件系统、传统身份接口 | 全部成功，文件系统报告NTFS | 同句柄核验全部成功 |
| 归档资源capture（包括全部祖先） | 抛出WinError87 | 成功 |
| 空目录清理的只读句柄信息查询 | 抛出WinError87 | 成功；未执行清理 |
| 同目录及父子目录资源重叠 | 无法完成读取 | 均正确识别重叠 |
| 归档影片目录枚举 | 被前置身份检查阻止 | 读取12个目录，条目错误为0 |

探针没有启动服务、没有写数据库、没有移动或删除任何NAS内容。真实路径、目录编号和影片名称不写入公开证据。私有原始输出在操作者本机 `.git/afk-smb87/nas-readonly-result.txt`。
