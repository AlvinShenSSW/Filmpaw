评审要点

本稿体现的已定决策

  • 各算一条 — 两条倉木華各占一行/一卡,各自打开
  • 失效置灰保留 — 小红@EAGLE 是失效示例,打开按钮仍可点,双开禁用
  • 别名共享 — 给任一条倉木華加的别名,搜索时两条都命中
  • 双向子串 + 繁简归一 — 仓木华↔倉木華;小红↔小红(仓木) 双向命中
  • 头像 (D9) — folder.jpg 缩略图入库;无则名字首字(橘底);失效行头像降透明

评审结论 (2026-07-25 定稿)

  • 橘色用量:维持现状(仅当前页标识/主按钮/选中态)
  • 结果样式:卡片式;头像为竖版 poster 比例,归档卡片 52×74
  • 失效清理:失效行单条删除(带确认)+ 工具栏"清理失效"批量按钮
  • merge 策略:merge-when-green;issues 建后先经 Codex 评审再跑 AFK
