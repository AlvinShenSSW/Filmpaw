# Poster 放大验收 (issue #27)

## 尺寸变更
| 位置 | 旧 | 新 | 倍数(线性/面积) |
|---|---|---|---|
| 表演者库 tile | 34×48 | **110×156** | 3.2× / ~10.5× |
| 归档匹配卡片 | 52×74 | **156×222** | 3.0× / ~9× |
| 缩略图入库上限 | 256px | **512px** | HiDPI 下 156×222 仍清晰 |

表演者库由表格改为响应式 poster 网格(`repeat(auto-fill, minmax(150px,1fr))`), §7.2 全部功能保留:
名字 / 别名 chips 增删(行内输入) / 短哈希 ID(tooltip 全量) / UNC 路径(poster tooltip) /
在线-失效状态 / 打开 / 失效删除 / 工具栏(搜索·来源筛选·显示失效·清理失效·全部重扫) /
分页"加载更多" / 底栏统计 / 空态 / 错误态重试。

## 真实迁移验证(既有 library.db, 非构造)
| 阶段 | 结果 |
|---|---|
| 启动旧库(v1 schema, 256px 缩略图) | `schema_version → 2`, **自动迁移未拒绝启动** |
| 迁移后 | 旧记录 `thumb_side=256`(显式记账, 非 NULL — 否则 SQL 比较为 NULL 永不重建) |
| 重扫后 | `thumb_side=512`, 缩略图按 512 上限重建 |
